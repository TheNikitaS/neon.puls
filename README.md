# НЕОН.ПУЛЬС

AI-платформа аналитики эффективности офлайн-бизнеса: видеоаналитика, посещаемость,
внимание к рекламе, продажи и финансовые показатели в одной системе — с разбором
каждой торговой точки и замкнутым циклом улучшений.

Это рабочий MVP по техническому заданию: личный кабинет компании, иерархия точек,
Integration Hub, аналитическое ядро, AI-аналитик, рекомендации, замер «до/после»,
уведомления, роли и административная панель платформы.

## Быстрый старт

```powershell
cd D:\Неон.Пульс
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

Откройте `http://127.0.0.1:8010`. При первом запуске база создаётся и наполняется
демо-данными: сеть кофеен, 12 точек в двух городах, 60 дней метрик и чеков.

Демо-доступы:

| Роль | Email | Пароль |
|---|---|---|
| Администратор компании | `demo@neonpulse.ru` | `Demo2026!` |
| Аналитик | `analyst@neonpulse.ru` | `Analyst2026!` |
| Суперадминистратор платформы | `admin@neonpulse.ru` | `NeonPulse2026!` |

Сквозная проверка API: `python scripts/smoke_test.py` (сервер должен быть запущен).

## Что уже работает

- **Личный кабинет компании** — регистрация организации, вход, переключение компаний,
  изоляция данных по `organization_id` на уровне каждого запроса.
- **Иерархия точек** — города/регионы, карточка точки, камеры и зоны, история изменений.
- **Integration Hub** — коннекторы Ivideon, универсальный POS и произвольный REST:
  создание, проверка соединения, синхронизация, журнал запросов и ошибок.
- **Аналитическое ядро** — трафик, внимание, входы, чеки, выручка, средний чек,
  конверсии, профили по часам и дням недели, рейтинг точек, сравнение периодов.
- **Дашборд по воронке** — четыре ключевых показателя: трафик, посмотревшие,
  вошедшие, купившие (чеки). Если камера внимания не подключена, показатель
  честно показывает «—» и подсказывает, как его включить.
- **Локальная ЦА точки** — сегменты аудитории с окнами активности, мотивом и
  тем, что может сработать. AI учитывает профиль ЦА вместе с адресом и районом.
- **Пилот и оценка точки** — настройки пилота (дата вывески, средний чек, цель
  роста), оценка визуальной эффективности по 10 параметрам с весами, гипотезы,
  план тестов, тренды и фото-аудит.
- **Ручной ввод денежных метрик** — выручка, чеки, средний чек, а также входы,
  просмотры и трафик вводятся вручную, если точка не подключена к кассе или API.
  Ручные данные за день заменяют данные интеграций за этот день и сразу попадают
  в дашборд, отчёты и AI-анализ.
- **AI-аналитик** — разбор точки и сети, уверенность вывода, источники, ограничения,
  рекомендации с планом замера, история выводов, вопросы по данным.
- **Замер «до/после»** — фиксация изменения, сравнение базового и результатного периода,
  эксперименты с вердиктом.
- **Уведомления** — аномалии по z-score, состояние интеграций.
- **Роли** — администратор компании, руководитель сети, региональный менеджер,
  управляющий точкой, аналитик; ограничение доступа к точкам через `scope`.
- **Админ-панель платформы** — организации, пользователи, интеграции, сводные метрики.

## Структура проекта

```
app/
  main.py            FastAPI: API + статический интерфейс
  config.py          конфигурация через переменные окружения
  database.py        SQLAlchemy, SQLite по умолчанию
  models.py          20+ сущностей из раздела 12 ТЗ
  schemas.py         Pydantic-схемы
  security.py        пароли (PBKDF2), JWT, шифрование ключей интеграций
  deps.py            контекст пользователя, роли, доступ к точкам
  seed.py            демо-данные
  services/
    analytics.py     KPI, динамика, сравнение, «до/после», аномалии
    ai_engine.py     правила, рекомендации, адаптер LLM
    integrations.py  коннекторы, нормализация, синхронизация
    notifications.py уведомления и мониторинг
  routers/           auth, org, locations, analytics, ai, integrations,
                     reports, notifications, admin
web/                 SPA без сборки: HTML, CSS, SVG-графики, vanilla JS
docs/                архитектура, API, план развития
scripts/             smoke_test.py
```

## Технологии

FastAPI + SQLAlchemy + Pydantic, SQLite (PostgreSQL — через `DATABASE_URL`),
JWT-сессии, PBKDF2 для паролей, Fernet для ключей интеграций. Интерфейс — без
сборки и внешних CDN: работает офлайн, графики рисуются собственным SVG-модулем.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DATABASE_URL` | подключение к БД | `sqlite:///data/neonpulse.db` |
| `NEONPULSE_SECRET` | секрет JWT и шифрования ключей | генерируется в `data/jwt_secret.txt` |
| `NEONPULSE_TOKEN_TTL_MIN` | время жизни токена, мин | `720` |
| `NEONPULSE_SANDBOX` | sandbox-режим коннекторов | `1` |
| `NEONPULSE_LLM_PROVIDER` | `rules` или `llm` | `rules` |
| `NEONPULSE_LLM_BASE_URL`, `NEONPULSE_LLM_API_KEY`, `NEONPULSE_LLM_MODEL` | внешняя LLM | — |
| `YANDEX_FOLDER_ID` | каталог Yandex Cloud | — |
| `YANDEX_API_KEY` | API-ключ сервисного аккаунта | — |
| `YANDEX_MODEL` | `yandexgpt-lite` или `yandexgpt` | `yandexgpt-lite` |

## Деплой в Yandex Cloud

Готовы `Dockerfile`, `docker-compose.yml` и пошаговая инструкция
[deploy/yandex-cloud.md](deploy/yandex-cloud.md): Container Registry,
Serverless Containers или VM, Managed PostgreSQL, сервисный аккаунт с ролью
`ai.languageModels.user` для YandexGPT.

AI-провайдер переключается переменной `NEONPULSE_LLM_PROVIDER=yandexgpt`.
Если модель недоступна, ядро автоматически отвечает детерминированно
(`fallback: rules`) — платформа не ломается.

## Импорт пилотной книги

Структура Excel-пилота (настройки, данные по дням, ЦА, гипотезы, тесты, тренды,
фото-аудит, оценка точки, рекомендации) переносится в платформу скриптом:

```powershell
python scripts/import_pilot_xlsx.py "D:\Неон.Пульс\Subjoy.xlsx"
```

Имя файла и значения — пример; скрипт читает структуру листов.

## Важно про данные и интеграции

- Демо-данные **синтетические и детерминированные**. Они нужны, чтобы платформа
  работала и проверялась без доступа к реальным камерам и кассам.
- Коннектор Ivideon реализует архитектуру обмена, но точный набор методов и
  показателей нужно сверить на реальном аккаунте и тарифе клиента: наличие API
  не означает, что все метрики доступны для каждой камеры.
- Показатель внимания к вывеске — приближённый (направление головы, остановки,
  время в зоне). Он не доказывает факт прочтения вывески и не даёт персональной
  атрибуции «этот человек совершил эту покупку».
- AI не выдаёт гипотезу за доказанную причину: у каждого вывода есть уверенность,
  источники и ограничения.

## Безопасность

Пароли — PBKDF2-SHA256 с солью; токены — JWT с истечением; ключи интеграций
шифруются и никогда не возвращаются в интерфейс (только маска). Каждый запрос
фильтруется по организации, доступ к точкам ограничен ролью и `scope`.
Действия с участниками пишутся в журнал аудита.
