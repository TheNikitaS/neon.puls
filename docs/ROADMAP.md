# План развития

Статус этапов из технического задания.

## Этап 1. Базовая платформа — готово

Регистрация, компании, личные кабинеты, роли, торговые точки, базовая
аналитическая панель, изоляция данных.

## Этап 2. Интеграция Ivideon — каркас готов

Коннектор, привязка камер к точкам, зоны, синхронизация, журнал ошибок.
Осталось: сверить реальные методы и состав метрик на аккаунте клиента,
добавить OAuth-поток Ivideon и вебхуки событий.

## Этап 3. Интеграция касс — каркас готов

Универсальный коннектор с маппингом полей, чеки, выручка, возвраты.
Осталось: подключить первую реальную кассовую систему, добавить дедупликацию
по `receipt_no` на уровне источника и сверку сумм.

## Этап 4. AI-аналитик — готово (правила + YandexGPT)

Разбор точки и сети, уверенность, ограничения, рекомендации, история,
вопросы по данным, локальная ЦА и адрес точки в каждом выводе. Подключён
адаптер YandexGPT через Yandex Cloud. Осталось: прогнозирование и сценарное
моделирование.

## Этап 5. Сетевые компании — готово

Иерархия город → точка, сравнение, рейтинг, региональные роли.
Осталось: сравнение одинаковых дней недели с поправкой на праздники,
групповые отчёты по регионам.

## Этап 6. Коммерческая платформа — частично

Тарифы и подписки в модели данных, уведомления, отчёты, админ-панель.
Осталось: биллинг и платежи, лимиты по тарифу, Telegram и email-каналы,
публичный API и вебхуки для клиентов.

## Ближайшие технические задачи

1. Фоновые задачи синхронизации (Celery/APScheduler) и расписание по интеграциям.
2. Материализация дневных агрегатов для больших объёмов.
3. PostgreSQL в production, миграции Alembic.
4. Ограничение частоты запросов и аудит чтения чувствительных данных.
5. Методика атрибуции внимания: пилот, валидация, публикация ограничений.
6. Резервное копирование и политика хранения видеоаналитических данных.
